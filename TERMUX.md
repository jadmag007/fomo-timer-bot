# Fomo Timer Bot на Android (Termux)

Бот целиком живёт на телефоне: напоминания приходят в тот же Telegram,
мини-апп открывается в браузере этого же телефона. Компьютер не нужен.

---

## Что понадобится

| Что | Где взять |
|-----|-----------|
| Android 8+ | — |
| **Termux** | **F-Droid** или GitHub Releases. ⚠️ Версия из Play Store устарела и не подходит |
| ~400 МБ места | Python + зависимости готовыми колёсами; запасная сборка с Rust — до 1.5 ГБ |
| Токен бота | уже есть у тебя (из .env на ПК) |

Установка Termux: открой https://f-droid.org/packages/com.termux/ в браузере
телефона → скачай APK → разреши установку из неизвестных источников → ставь.

## Установка бота (10 минут)

Открой Termux и выполни по очереди:

```bash
pkg update -y && pkg upgrade -y
pkg install -y git
git clone https://github.com/jadmag007/fomo-timer-bot
cd fomo-timer-bot
bash install.sh
```

`install.sh` сам увидит Termux и сделает всё сам: поставит Python, заберёт
pydantic-core (Rust-расширение aiogram) ГОТОВЫМ колесом из зеркала TUR PyPI
и доставит остальные зависимости — без компиляции, обычно 2-5 минут.
Если зеркало недоступно, install.sh сам переключится на запасную сборку
через Rust из репозитория Termux (10-25 минут, разовая). Когда спросит
токен — вставь его длинным тапом → Paste.

Если репозитория нет под рукой — можно развернуть из zip:

```bash
pkg install -y unzip
unzip fomo-timer-bot.zip
cd fomo-timer-bot
bash install.sh
```

Запуск бота: `bash start.sh`. Он сам берёт wake-lock и сам перезапускает бота
при падении. Остановка: Ctrl+C (кнопка Ctrl в дополнительной строке
клавиатуры Termux, или зажми «Громкость вниз» и нажми C).

> **Почему `bash install.sh`, а не `./install.sh`?** Git при пуше с Windows
> не сохраняет бит «исполняемый файл» — после `git clone` на андроиде
> `./install.sh` отвечал бы «Permission denied». Запуск через `bash` работает
> всегда. Права можно вернуть и руками: `chmod +x *.sh` (install.sh делает
> это сам при каждом запуске).

## Перенос данных с ПК через свой репозиторий (5 минут)

`.env` и `data/` в git не попадают по задумке — там токен и личные данные,
.gitignore их бережёт. Поэтому в свой репозиторий их «проталкивают» один
раз принудительно, а телефон забирает обычным `git pull`.

**Шаг 0. Репозиторий должен быть ПРИВАТНЫМ** (иначе токен увидит весь
интернет). Открой https://github.com/jadmag007/fomo-timer-bot →
**Settings → General**, прокрути в самый низ до **Danger Zone** →
**Change repository visibility** → **Make private** → подтверди, введя
имя репозитория.

**Шаг 1. Дай телефону право читать приватное** (один раз). На GitHub:
аватар справа вверху → **Settings → Developer settings → Personal access
tokens → Tokens (classic) → Generate new token (classic)**: Note —
`fomo-phone`, срок любой (можно No expiration), галочка **repo** →
**Generate token**. Скопируй токен (начинается с `ghp_`) — его показывают
один раз, он понадобится в шаге 3.

**Шаг 2. С ПК отправь данные.** Останови бота (Ctrl+C в его окне), открой
cmd:

```
cd F:\FOMO\fomo-timer-bot
git add -f .env data
git rm --cached --ignore-unmatch "data/*.session" "data/*.session-journal" "data/*.log"
git commit -m "sync data pc to phone"
git push
```

`-f` проталкивает игнорируемое; строка с `rm --cached` вынимает из посылки
сессию Telegram и логи (сами файлы на ПК остаются — в git им не место).

**Шаг 3. На телефоне забери** (Termux):

```bash
cd ~/fomo-timer-bot
git config core.fileMode false
git config credential.helper store
git pull
```

Спросит Username: `jadmag007`, Password: длинный тап по экрану → Paste →
вставь токен из шага 1 (символы не отображаются — это норма). Готово:
`.env` и `data/` лежат в папке бота.

⚠️ Сессию юзербота (`userbot.session` — вход в твой Telegram) через git не
возим намеренно: на телефоне она не нужна, а если понадобится — там же
выполни `bash login_bot.sh`.

**Дальше данные обновляются так:** останови бота на обеих сторонах →
на той, где свежие данные, повтори шаг 2 → на другой стороне `git pull` →
запусти бота. Правило «один бот = один запущенный экземпляр» действует
как всегда.

Остальное поставит `install.sh`. После переноса проверь: `bash start.sh` →
в консоли появится список загруженных напоминаний и `FOMO auth ok`.

## ⚠️ Главное правило: один бот = один запущенный экземпляр

Если бот запущен **и на ПК, и на телефоне одновременно**, Telegram начнёт
выдавать `409 Conflict: terminated by other getUpdates request` — пушами
будет шуметь то один, то другой. Включи бота только на чём-то одном.
Второй экземпляр как «холодный резерв» — нормально, просто не держи оба
запущенными.

## Чтобы Android не убил бота

Android агрессивно замораживает фоновые процессы. Три шага против этого:

1. **Wake-lock** — `start.sh` берёт его сам (строка `termux-wake-lock`),
   ничего делать не надо. Уведомление «Termux: acquiring wakelock» — норма.
2. **Батарея без ограничений**: Настройки → Приложения → Termux →
   Батарея → «Без ограничений» (на некоторых прошивках — «Не оптимизировать»).
3. **Не свайпай Termux** из списка недавних приложений — это убивает процесс.

При перезагрузке телефона бот сам не стартует. Хочешь автозапуск —
поставь приложение **Termux:Boot** (тоже с F-Droid), открой его один раз,
затем:

```bash
mkdir -p ~/.termux/boot
cat > ~/.termux/boot/fomo.sh << 'EOF'
#!/data/data/com.termux/files/usr/bin/bash
termux-wake-lock
cd ~/fomo-timer-bot
bash start.sh
EOF
chmod +x ~/.termux/boot/fomo.sh
```

## Мини-апп на телефоне

Всё уже работает: локальный режим (v0.1.0.2) слушает на этом же устройстве.

1. Бот запущен (`./start.sh`)
2. Открой в браузере телефона: **http://127.0.0.1:8080**
3. Или прямо из Termux: `termux-open http://127.0.0.1:8080`

В Chrome можно «Добавить на главный экран» — будет иконка на весь экран,
как приложение.

**Туннель на андроиде:** автоматически скачается arm64-сборка cloudflared
(начиная с v0.1.0.3). Приятный бонус: на мобильном интернете туннель часто
РАБОТАЕТ — у сотового оператора порт 7844 обычно не заблокирован, в отличие
от домашнего провайдера. Тогда мини-апп откроется и с других устройств
по адресу из консоли/пуша.

## Обновление бота

Если ставил через git:

```bash
cd ~/fomo-timer-bot
git pull
bash start.sh
```

`.env` и `data/` git не трогает. Если ставил из zip — распакуй новый zip
поверх папки (кроме личных файлов, как при первом переносе) и перезапусти.

## Расход батареи

Wake-lock держит процессор активным, поэтому расход заметный. Реалистичная
оценка: 3–8% за ночь у бота в кармане. Если телефон живёт от зарядки или
это второй/старый телефон — вообще не проблема. Игра сама по себе всё равно
требует открытого Telegram на основном телефоне — боту хватает фонового
процесса, экран включать не надо.

## Troubleshooting

| Симптом | Причина и лечение |
|---------|-------------------|
| pip не смог поставить `pydantic-core` (зеркало недоступно) | Просто повтори `bash install.sh` позже — всё встанет готовым колесом. Срочно: `pkg install -y rust binutils`, затем `pip install --extra-index-url https://termux-user-repository.github.io/pypi/ maturin` и снова `bash install.sh` (rustup НЕ подходит — он не умеет андроид-таргет) |
| `./install.sh`: Permission denied | Git с Windows не хранит exec-бит: запускай `bash install.sh` и `bash start.sh` — работает всегда (или один раз `chmod +x *.sh`) |
| Бот «засыпает» через пару часов | Оптимизация батареи: см. раздел выше (пункт 2) |
| `409 Conflict` в логе | Где-то запущен второй экземпляр с тем же токеном — останови на ПК или на телефоне |
| `pip` ругается при установке | см. первые две строки таблицы; затем снова `bash install.sh` |
| Частые сетевые обрывы в логе | Мобильный интернет; бот перезапрашивает сам, это не ошибка |
| `Exec format error` от cloudflared | Старая версия бота (до 0.1.0.3) качала amd64-сборку — обновись |
| Termux просит хранилище | Не нужно: боту хватает своей папки в домашнем каталоге Termux |
