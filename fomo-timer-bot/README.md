# ⏱ Fomo Timer Bot — уведомления для Fomo Fighters

Мини-апп Fomo Fighters не может присылать уведомления (ограничение Telegram
Mini Apps: это веб-страница внутри Telegram, без доступа к нативным пушам
Android — поэтому любые «будильники» игры опаздывают или не приходят вовсе).

**Этот бот решает проблему:** вы ставите таймер на время улучшения, а в момент
финиша приходит **обычный пуш Telegram** — он доставляется мгновенно, со звуком,
даже если игра и бот закрыты. Таймеры хранятся в SQLite на сервере: телефон
можно выключать, перезагружать, уезжать без связи — ничего не потеряется.

```
Вы запустили улучшение в игре (на кнопке таймер 22:24)
        │
        ▼
/т 22:24 лесопилка      ← 2 секунды, формат ровно как в игре
        │
        ▼ (время вышло)
«✅ Готово! Лесопилка…»  ← пуш Telegram, секунда в секунду
```

## Возможности

| Режим | Статус | Описание |
|---|---|---|
| **Ручные таймеры** | ✅ готово | Чипы 5м…24ч в меню, «Своё время», команда `/т` с игровым форматом времени |
| **Только T-0** | ✅ включено | Одно сообщение «Готово ✅» в момент финиша (без шума) |
| **Автотрекинг через API** | 🔧 заготовка | Бот сам видит запущенные улучшения и ставит таймеры. Нужна одна настройка после снятия трафика (см. ниже) |

Дополнительно: список активных таймеров с отменой, выбор часового пояса,
предупреждение «за минуту» отключено, но включается одной строкой в `.env`
(`WARN_ENABLED=true`).

## Шаг 0. Создание бота в Telegram (2 минуты)

1. Откройте [@BotFather](https://t.me/BotFather) → команда `/newbot`.
2. Имя (например, `Fomo Timer`) → username, оканчивающийся на `bot` (например, `my_fomo_timer_bot`).
3. BotFather пришлёт **токен** вида `7712345678:AAF3x…` — он понадобится на шаге 1.
4. (Необязательно) `/setcommands` → выберите бота → вставьте:
   ```
   t - ⏱ Таймер: /t 22:24 лесопилка
   timers - 📋 Активные таймеры
   tz - 🌍 Часовой пояс
   help - ❓ Справка
   ```

## Шаг 1. Установка на VPS

Подойдёт любой дешёвый VPS / бесплатный Oracle Cloud Free Tier (Ubuntu 22.04+).
Нужен Python 3.11+ (в Ubuntu 22.04 уже есть 3.10 — тогда сначала
`sudo apt install python3.11 python3.11-venv`).

```bash
# 1. Код
sudo mkdir -p /opt/fomo-timer-bot && cd /opt/fomo-timer-bot
# загрузите файлы проекта (scp/WinSCP/git) так, чтобы здесь оказался bot.py

# 2. Окружение и зависимости
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 3. Конфигурация
cp .env.example .env
nano .env            # вставьте BOT_TOKEN, при желании API_OWNER_TG_ID

# 4. Тестовый запуск (в логах должно появиться «Бот запущен»)
.venv/bin/python bot.py
# Остановите Ctrl+C и переходите к автозапуску

# 5. Автозапуск как сервис
sudo cp systemd/fomo-timer.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now fomo-timer
journalctl -u fomo-timer -f        # смотреть логи
```

### Альтернатива: Docker

```bash
cp .env.example .env && nano .env
docker compose up -d --build
docker compose logs -f
```

### Проверка

Откройте бота в Telegram → `/start` → тапните «5м» → через 5 минут придёт
«✅ Готово!». Если пуша нет — см. FAQ ниже.

## Команды бота

| Команда | Пример | Что делает |
|---|---|---|
| `/т` | `/т 22:24 лесопилка` | Таймер в игровом формате: `22:24` = 22 мин 24 с; `1:28:10` = чч:мм:сс; `1ч 30м`, `45м`, `30с`, `90` (минуты) |
| `/таймеры` | | Список активных + отмена кнопкой ❌ |
| `/пояс` | `/пояс` | Часовой пояс (для отображения времени финиша) |
| `/help` | | Справка |
| чипы в меню | `5м 15м 30м 45м 1ч…` | Таймер в один тап |
| «✍️ Своё время» | `22:24 лесопилка` | Ввод текстом, подпись необязательна |

**Совет:** время удобно перепечатывать прямо с кнопки улучшения в игре
(`Улучшить ⏱ 22:24`) — формат совпадает один в один.

## Автотрекинг (Вариант 2): чтобы бот ставил таймеры сам

Мини-апп — это веб-приложение, его общение с сервером игры можно увидеть
в DevTools. Цель — найти эндпоинт, который отдаёт состояние города с временем
окончания улучшений, и токен авторизации. Это делается **один раз**.

### Шаг 1. Снять трафик в Telegram Desktop

1. Установите актуальный **Telegram Desktop** (telegram.org) — не портативную сборку.
2. Откройте чат `@fomo_fighters_bot` → запустите мини-апп (кнопка ▶️/«PLAY» или кнопка меню).
3. **Правый клик** по окну игры → **«Inspect» / «Проверить»** — откроется DevTools.
   *Пункта нет? Обновите Telegram Desktop; в некоторых версиях пункт находится в
   меню «⋮» в заголовке мини-аппа. Внутри самой игры правый клик может
   перехватываться канвасом — кликайте по рамке/заголовку окна.*
4. В DevTools откройте вкладку **Network** → фильтр **Fetch/XHR**.
5. Обновите состояние игры: закройте мини-апп и откройте заново (или переключите
   экраны «Город → Здания → Лесопилка → Назад»). В списке появятся запросы.
6. Нажмите красную кнопку записи ⏺ (если запросы уже прошли — повторите
   перезагрузку мини-аппа при включённой записи).
7. Правой кнопкой по списку запросов → **«Save all as HAR with content»** →
   сохраните файл, например `fomo.har`.

**Важно:** в HAR будет ваш токен авторизации. Не выкладывайте его публично —
только в этот чат (при необходимости токен обновляется перезапуском мини-аппа).

### Шаг 2. Прогнать анализатор

На любом компьютере с Python 3:

```bash
python tools/har_inspect.py fomo.har
# если сразу видно домен API, можно сузить:
python tools/har_inspect.py fomo.har --host api.fomofighters.…
```

Скрипт выведет:
- все запросы к API игры (метод/URL/статус);
- **кандидатов** — ответы с полями, похожими на таймеры (`finished_at`,
  `remaining`, `time_left`, `upgrade_end`…), с JSON-путями и значениями;
- заголовок авторизации (его вставим в `.env` → `API_AUTH_HEADER`);
- сохранит всё в **`har_report.txt`** (включая полный JSON ответа кандидата).

### Шаг 3. Заполнить автотрекинг (2 строки кода)

Пришлите `har_report.txt` — по нему заполняются две вещи:
1. В `api_poller.py`: путь эндпоинта в `fetch_state()` и разбор ответа в
   `extract_upgrades()` (обычно 5–15 строк).
2. В `.env`:
   ```
   API_ENABLED=true
   API_BASE_URL=https://<домен API из отчёта>
   API_AUTH_HEADER=Authorization: Bearer <токен из отчёта>
   API_OWNER_TG_ID=<ваш id, узнать у @userinfobot>
   ```
3. `sudo systemctl restart fomo-timer` — в логах появится «API-автотрекинг запущен».

После этого бот раз в 45 секунд сверяется с игрой и **сам ставит таймеры** на
каждое запущенное улучшение. Останется только получать пуши.

### Если что-то пошло не так

| Симптом | Причина / решение |
|---|---|
| DevTools пустой, запросов нет | Запись Network надо включить **до** перезагрузки мини-аппа; повторите шаг 5 |
| В HAR только telegram.org | Игра грузит данные с собственного домена — пришлите `har_report.txt`, найдём фильтром |
| «401 Unauthorized» в логах бота | Токен истёк — переоткройте мини-апп, снимите новый заголовок, обновите `.env` |
| Ответ сжат/нечитаем | В DevTools включите «Save all as HAR **with content**» |

### Про безопасность и правила игры

Бот читает только **свои** данные через GET-запросы (read-only) — это то же
самое, что вы видите глазами в приложении. Никаких действий за вас он не
совершает и автоматизацией геймплея не является. Тем не менее это
неофициальный инструмент: теоретически политика игры может этого не
одобрять — используйте на свой страх, риск минимальный, но не нулевой.

## FAQ

**Пуши приходят с задержкой?**
Telegram доставляет мгновенно; задержки бывают, если в самом Telegram отключён
фоновый режим/автозапуск. Проверьте: Настройки ТГ → Уведомления и звук;
в Android — не «усыплён» ли Telegram (Настройки → Батарея → Без ограничений).

**Бот молчит после `/start`?**
Проверьте токен в `.env` и `journalctl -u fomo-timer -f`. Если у вас уже был
запущен другой экземпляр бота с этим токеном — остановите его (два polling-
процесса с одним токеном конфликтуют).

**Бот перезапустился — таймеры сгорят?**
Нет. Всё лежит в `data/fomo_timers.db`; после старта бот догонит пропущенные
уведомления с пометкой «опоздание N мин».

**Можно вернуть предупреждение «за минуту до конца»?**
Да: в `.env` поставьте `WARN_ENABLED=true` и перезапустите.

**Часовой пояс?**
По умолчанию `Europe/Moscow`; меняется командой `/пояс`. Влияет только на
отображение времени финиша, на точность — нет.

## Структура проекта

```
fomo-timer-bot/
├── bot.py               # точка входа: диспетчер aiogram + фоновые задачи
├── handlers.py          # команды и кнопки (ручные таймеры)
├── timers.py            # планировщик: T-0 «Готово ✅» (+ опционально T-1мин)
├── api_poller.py        # автотрекинг по API игры (заполняется на шаге 3)
├── db.py                # SQLite: пользователи и таймеры
├── util.py              # парсер игрового времени (22:24 / 1ч 30м / 45м)
├── config.py            # чтение .env
├── tools/
│   └── har_inspect.py   # анализ HAR-экспорта → поиск эндпоинтов и токена
├── systemd/
│   └── fomo-timer.service
├── Dockerfile / docker-compose.yml
├── requirements.txt
└── .env.example
```
