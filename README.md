# ⏱ Fomo Timer Bot — уведомления для Fomo Fighters

**Версия: 0.0.4-alpha**

Мини-апп Fomo Fighters не может присылать уведомления (ограничение Telegram
Mini Apps: это веб-страница внутри Telegram, без доступа к нативным пушам
Android — поэтому любые «будильники» игры опаздывают или не приходят вовсе).

**Этот бот решает проблему:** вы ставите таймер на время улучшения, а в момент
финиша приходит **обычный пуш Telegram** — он доставляется мгновенно, со звуком,
даже если игра и бот закрыты. Таймеры хранятся в SQLite на компьютере: телефон
можно выключать, перезагружать, уезжать без связи — ничего не потеряется.

```
Вы запустили улучшение в игре (на кнопке таймер 22:24)
        │
        ▼
/т 22:24 лесопилка      ← 2 секунды, формат ровно как в игре
        │
        ▼ (время вышло)
«✅ Готово! Лесопилка…»  ← пуш Telegram, секунда в секунду
```

Версия помечена **alpha**: основной функционал работает стабильно (проверено на
живом аккаунте), интерфейс и формат логов могут немного меняться до беты.

## Возможности

| Режим | Статус | Описание |
|---|---|---|
| **🎯 Мини-приложение в боте** | ✅ готово | Кнопка меню ☰: ВСЕ таймеры на одном экране с живыми отсчётами + кнопки управления (тихий режим по группам, отмена, «Обновить»). Уведомления в чат приходят как раньше |
| **Ручные таймеры** | ✅ готово | Чипы 5м…24ч в меню, «Своё время», команда `/т` с игровым форматом времени |
| **Только T-0** | ✅ включено | Одно сообщение «Готово ✅» в момент финиша (без шума) |
| **Автотрекинг через API** | ✅ готово | Бот сам видит запущенные улучшения и ставит таймеры. Включение — один раз: либо `login_bot.bat` (юзербот, навсегда), либо файл `fomo.txt` в папку бота |
| **Самоподпись + авто-продление ключа** | ✅ готово | Бот сам вычисляет подпись каждого запроса и сам продлевает ключ через `auth` — файлы трафика нужны всё реже |
| **🎁 Клановые сундуки и аванпосты** | ✅ готово | Перезарядка клановых сундуков (сундук clan_N открывается с уровня клана N и перезаряжается N часов) и награды аванпостов — из `/user/data/all`, с понятными подписями. Статус этого опроса виден в `/апи` |
| **🚩 Осада аванпоста: предупреждение за час** | ✅ готово | За час до конца осады приходит отдельный пуш «пора отправлять войска» (порог — `SIEGE_PREWARN_SEC` в .env) |
| **✨ Скрытые поля-даты** | ✅ готово | Прочие кулдауны вне основных списков (лимит осад и т.п.) — ставятся автоматически с меткой «✨» |
| **Переводы таймеров** | ✅ готово | Все подписи — в одном файле `translations.py`; неизвестный ключ показывается английским именем и не ломает ничего |
| **Трассировка API** | ✅ готово | `/трассировка` — лог сырых ответов игры в `data/trace.log`, `/трейслог` — прислать файл. По нему добавляются новые таймеры и переводы |

Дополнительно: список активных таймеров с отменой, выбор часового пояса,
предупреждение «за минуту» отключено, но включается одной строкой в `.env`
(`WARN_ENABLED=true`).

## Шаг 0. Создание бота в Telegram (2 минуты)

1. Откройте [@BotFather](https://t.me/BotFather) → команда `/newbot`.
2. Имя (например, `Fomo Timer`) → username, оканчивающийся на `bot` (например, `my_fomo_timer_bot`).
3. BotFather пришлёт **токен** вида `7712345678:AAF3x…` — он понадобится на шаге 1.
4. (Необязательно) `/setcommands` → выберите бота → вставьте:
   ```
   t - ⏱ Таймер: /t 22:24 лесопилка
   timers - 📋 Активные таймеры
   app - 🎯 Мини-апп: все таймеры и кнопки
   tz - 🌍 Часовой пояс
   api - 🤖 Статус автотрекинга
   ask - 🔔 Подтверждение таймеров вкл/выкл
   trace - 🧪 Трассировка API вкл/выкл
   help - ❓ Справка
   ```

## Шаг 1. Где запускать бота

### Вариант А. Локально на ПК — рекомендую для старта (5 минут, без команд)

Скачайте и распакуйте `fomo-timer-bot.zip` в любую папку, дальше — **один файл**:

| ОС | Действие |
|---|---|
| **Windows** | Двойной клик по **`install.bat`**. Он сам: найдёт или установит Python, поставит зависимости, спросит **только токен** от @BotFather и сразу запустит бота. Впоследствии бот запускается двойным кликом по **`start.bat`** |
| **macOS / Linux** | В терминале в папке проекта: `./install.sh` (потом — `./start.sh`) |

Скрипт-установщик умеет перезапускать бота при падении (окно держим открытым, можно свернуть).

> ⚠️ **Честное предупреждение:** на локальном ПК уведомления приходят только пока ПК
> включён и не спит. Если таймеры ставите на ночь — отключите сон ПК
> (Windows: Параметры → Система → Питание → «Переводить в спящий режим: никогда»)
> или позже перенесите бота на VPS (Вариант Б) — настройки и база таймеров переезжают
> простой заменой файлов.

### Вариант Б. VPS 24/7 — когда захотите, чтобы работало всегда

Подойдёт любой дешёвый VPS / бесплатный Oracle Cloud Free Tier (Ubuntu 22.04+).
Нужен Python 3.11+ (в Ubuntu 22.04 уже есть 3.10 — тогда сначала
`sudo apt install python3.11 python3.11-venv`).


## 🎯 Мини-приложение в боте: все таймеры на одном экране

Пуши удобны, когда их мало. Когда таймеров много (стройка + войска + сундуки),
удобнее открыть **мини-приложение** — панель прямо в Telegram, где сразу видно
всё: живые отсчёты, прогресс-бары, группы. Открывается двумя способами:

- **кнопка меню ☰** слева от поля ввода у бота (там, где раньше список команд);
- команда **`/app`** (или `/приложение`) — придёт кнопка-ссылка на ту же панель.

### Что внутри

- **Все таймеры группами** (🏗 Стройка, ⚔️ Тренировка, 🎁 Сундуки…) с большими
  живыми отсчётами и временем финиша в вашем поясе; у осад аванпоста — метка
  «🚩 за час напомнит о войсках».
- **🔔/🔕 у каждой группы** — тихий режим точечно: например, заглушить
  клановые сундуки (они перезаряжаются каждые 1–14 часов и шумят часто).
  Заглушённая группа НЕ шлёт пушей вовсе (и не «накапливает» их на потом),
  но таймеры видны в панели как обычно.
- **🔕 «Тихий режим»** внизу — то же самое, но сразу для всех групп.
- **✕ на карточке** — отменить таймер (с подтверждением).
- **🔄 «Обновить»** — внеочередной опрос API игры: только что запущенное в игре
  улучшение появится на экране через пару секунд, не дожидаясь обычного цикла.
- **🎮 «Игра»** — открыть мини-апп Fomo Fighters одной кнопкой.
- Экран сам обновляется каждые 30 с (и сразу при возвращении в окно),
  пустое состояние подсказывает, что делать, если таймеров нет.

### Как это работает (и почему всё безопасно)

Telegram открывает мини-приложения только по HTTPS с действительным
сертификатом, а бот у вас дома без белого IP. Поэтому при старте бот сам
(без регистрации и токенов) поднимает бесплатный туннель **cloudflared**:
при первом запуске скачает его (~20 МБ, рядом с ботом), запустит и получит
адрес вида `https://xxx.trycloudflare.com`. Адрес меняется при каждом
рестарте — кнопка меню обновляется автоматически, ничего перенастраивать
не нужно.

Доступ защищён официальной схемой Telegram Mini Apps: страница получает
подписанный Telegram `initData` и передаёт его с каждым запросом, сервер
проверяет подпись **вашего** бота и то, что пользователь — владелец. Чужой,
даже узнав адрес, получит отказ. Локальный сервер слушает только `127.0.0.1`.

Пуши (уведомления в чат) **не зависят** от мини-аппа: если туннель не поднялся
(нет интернета, Cloudflare недоступен), уведомления продолжат приходить
как раньше, а `/апи` покажет «🎯 Мини-апп: поднимаю туннель…». Лог туннеля:
`data/tunnel.log`.

Настройки в `.env`:

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `WEBAPP_ENABLED` | `true` | `false` — выключить мини-апп полностью |
| `WEBAPP_PORT` | `8080` | Локальный порт (занят — берётся следующий) |
| `WEBAPP_PUBLIC_URL` | пусто | Свой HTTPS-адрес (VPS/свой туннель) — тогда cloudflared не скачивается |

> Тихий режим — это про пуши, а не про сами таймеры: автотрекинг продолжает
> ставить их, история сохраняется, всё видно в панели. Настройки хранятся в
> `data/webapp_settings.json` и переживают рестарт.

## Автотрекинг: бот ставит таймеры сам

Мини-апп — это веб-приложение: когда игра показывает таймер улучшения, эти же
данные лежат на сервере игры. Бот умеет сам забирать их по API: заметил новое
запущенное улучшение → поставил таймер → прислал «✅ Готово!» в момент финиша.
Вручную вводить время больше не нужно.

**Как это устроено (коротко).** Игра авторизуется запросом `/telegram/auth` с
обычной Telegram-подписью (initData), а каждый запрос подписывает простым
hash-ем от времени и тела — никаких секретов. Бот делает то же самое сам:
однажды получив initData, он сам подписывает каждый запрос и сам продлевает
ключ, когда сервер его сбрасывает (это случается при переподключении игры).
Когда initData окончательно устареет, свежую добудет юзербот — Telegram-сессия,
созданная один раз через `login_bot.bat`.

Новые таймеры по умолчанию добавляются **молча, без вопросов**. Хотите сначала
видеть список и подтверждать — пришлите боту `/вопросы`.

### Путь 1 (рекомендую): юзербот — один вход, навсегда

1. Запустите **`login_bot.bat`** (Windows) или `./login_bot.sh` (macOS/Linux)
   в папке бота.
2. Введите телефон (в формате +7…), затем код, который придёт в Telegram,
   и пароль 2FA — если он включён.
3. Увидите «ОК: мини-апп открылся, initData получена» — всё.

> **Если вход упал с «403 RECAPTCHA_CHECK…»** — это анти-спас Telegram против
> ботов на встроенных «публичных» api-ключах (ваш аккаунт ни при чём). Впишите
> свои бесплатные ключи: [my.telegram.org](https://my.telegram.org) →
> «API development tools» → создайте приложение (App title / Short name любые,
> Platform: Desktop) → скопируйте `app_api_id` и `app_api_hash` → впишите в `.env`
> строки `USERBOT_API_ID=…` и `USERBOT_API_HASH=…` → запустите `login_bot.bat`
> снова. Скрипт входа при такой ошибке сам предложит ввести ключи и сохранит
> их в `.env`.

Больше вы не делаете ничего: бот сам получает ключи игры, сам их продлевает,
сам обновляет initData, когда та истечёт. Никаких файлов трафика.

> Файл `userbot.session` после входа — это ваш личный вход в Telegram.
> Не передавайте его никому и не выкладывайте.

### Путь 2 (быстрый старт): файл fomo.txt — 5 минут

Если хочется включить прямо сейчас, без входа по телефону: снимите трафик
по инструкции ниже и положите файл боту — он вытащит из него initData и
перейдёт в тот же нативный режим (сам подпишет и сам продлит ключ). Когда
initData со временем истечёт, бот напишет «запустите login_bot.bat» — и вы
перейдёте на Путь 1 (либо просто положите свежий `fomo.txt`).

## 📁 Файл fomo.txt — главный ключ автотрекинга

`fomo.txt` — самый важный файл всего проекта. Это **снимок обмена игры с
сервером** (формат HAR), из которого бот достаёт initData — «пропуск» в API
Fomo Fighters. Пока юзербот не настроен, именно `fomo.txt` включает и
обновляет автотрекинг. Ниже — всё о нём на основе реального опыта настройки.

### Что внутри и почему этого достаточно

В файле — все запросы, которые мини-апп отправил с момента открытия. Ключевой
из них — **`POST /telegram/auth`**: игра шлёт его при каждой загрузке и внутри
передаёт initData. Бот извлекает initData и дальше работает **сам**:

- сам подписывает каждый запрос к API (`Api-Key`/`Api-Time`/`Api-Hash`);
- сам продлевает ключ через повторный `auth` (в том числе при 401);
- опрашивает `/user/data/timers` и ставит таймеры.

Поэтому режим **«Copy all as HAR» (без тел ответов) подходит полностью** —
даже «Save all as HAR with content» не обязателен: тела ответов боту не нужны,
initData живёт в заголовках и теле запроса `/telegram/auth`.

### Как получить fomo.txt (5 минут, браузер)

1. Откройте в Chrome / Edge / Я.Браузере адрес **web.telegram.org** и войдите
   в свой Telegram: на телефоне → Настройки → Устройства → «Связать с
   настольным устройством» → отсканируйте QR-код с экрана компьютера.
2. Откройте чат с игрой и запустите мини-апп (кнопка ▶️ / «PLAY») — игра
   откроется прямо на странице.
3. Нажмите **F12** — внизу откроется панель разработчика. Перейдите на
   вкладку **Network** (Сеть), включите фильтр **Fetch/XHR**, убедитесь, что
   запись включена (красная точка ⏺).
   *Если игра открылась в отдельной вкладке — F12 нажимайте в ней.*
4. **Перезагрузите игру**: закройте мини-апп и откройте заново. Походите по
   экранам (Город → Здания → постройки) — в списке Network побегут запросы.
   Важно: запись Network должна работать ДО перезагрузки мини-аппа, иначе
   список останется пустым.
5. Правый клик по любому запросу в списке → **«Copy» → «Copy all as HAR»**,
   откройте Блокнот, вставьте (Ctrl+V), сохраните как **`fomo.txt`**
   (кодировка UTF-8).
   *Есть пункт «Save all as HAR with content» — можно сохранить сразу .har,
   тоже подойдёт.*

> ⚠️ Внутри HAR — данные вашего аккаунта (initData = ваш временный ключ игры).
> Не выкладывайте файл публично. В личный чат с ботом/разработчиком присылать
> можно, но помните: файл умирает сам, когда игра переподключается.

### Куда положить fomo.txt — 3 способа (все без команд)

| Способ | Как | Когда удобен |
|---|---|---|
| **1. Просто в папку бота** | Скопируйте `fomo.txt` рядом с `bot.py` (корень папки). Бот заметит файл за пару секунд — если юзербот не настроен, сам «съест» файл и настроится. Повторно тот же файл не трогается; обновлённый — подхватится снова | Самый простой путь |
| **2. В папку `token_updates/`** | Бросьте файл в эту папку рядом с ботом | Когда папка уже открыта в проводнике |
| **3. Drag&drop на `update_token.bat`** | Перетащите `fomo.txt` на ярлык | Быстро, прямо из «Загрузок» |

Требования для всех способов: **бот запущен** (окно `start.bat` открыто),
расширение файла — `.txt`/`.har`/`.json`/`.log`/`.curl`, имя начинается с
`fomo` для способа 1 (например, `fomo.txt`, `fomo2.har`).

Что произойдёт дальше:

1. Бот найдёт `/telegram/auth` и извлечёт initData — ключ нативного режима.
2. Пропишет всё в `.env` и включит автотрекинг (без рестарта).
3. Сделает контрольный цикл: auth + запрос таймеров — со СВОЕЙ подписью.
4. Напишет в личку: **«🔑 Токен обновлён ✅»** + результат проверки.
5. Найденные таймеры добавит молча (список — `/таймеры`).
6. Файл переедет в `token_updates/done/` — там ваш токен, наружу не выкладывайте.

### Когда fomo.txt нужен снова

Ключ игры привязан к сессии игры: при каждом переподключении мини-аппа сервер
сбрасывает старые подписи. В нативном режиме бот переживает это сам (повторный
auth). Но initData не вечна — когда она окончательно устареет, в `/апи` появится
«initData не принимается», и в личку придёт сообщение. Тогда:

- с юзерботом (Путь 1) — ничего делать не нужно, бот добудет ключ сам;
- без юзербота — положите свежий `fomo.txt` любым способом из таблицы выше.

Признак «пора обновить файл» один: сообщение бота про initData + 401 в `/апи`.
Семь дней работы без файлов — норма при настроенном юзерботе; без него файл
требуется раз в несколько дней (зависит от того, как часто игра переподключается).

## Новые таймеры и переводы (translations.py + трассировка)

Все подписи таймеров собираются в одном файле — **`translations.py`**:

- `BUCKETS` — группы таймеров (списки `tBuildings`, `tTroops`, `tSkills`…);
- `BUILDINGS` — названия зданий (ключи `buildingKey`);
- `TROOPS` — войска (ключи `troopKey`);
- `SKILLS` — навыки (ключи `skillKey`).

Формат словаря: `"ключ_игры": "по-русски"`. Нет ключа — бот не падает и
показывает приличное английское имя (`clan_chest` → «Clan chest»), а таймер
продолжает работать. Поэтому часть таймеров у вас уже переведена (здания),
а часть — пока английские (войска, навыки): их ключи неизвестны, как только
увидим их в трассировке — добавим перевод за минуту.

Клановые сундуки и награды аванпостов приходят отдельным эндпоинтом
`/user/data/all` (списки `stClanRewards` / `stOutpostRewards`) — бот опрашивает
его раз в 5 минут (`FOMO_ALL_INTERVAL` в .env) и ставит таймеры с подписями
«🎁 Клановый сундук · 7 ч» и «📦 Награда аванпоста · кольцо 1, ур. 1».
Механика сундуков подтверждена таблицей `dbClanRewards` из конфига игры:
сундук `clan_N` доступен при уровне клана N и перезаряжается N часов
(1 ч … 30 ч), сундуков ровно столько, каков уровень клана; собрать доступные
сразу можно одной кнопкой в игре. Прочие поля-даты вне основных списков
(кулдауны) бот ставит с меткой «✨» в подписи.

**Проверить, что сундуки опрашиваются:** откройте `/апи` — там есть строка
«🎁 Сундуки/аванпосты (раз в 300 с): … · HTTP 200 · нашёл N, новых M». Если
вместо неё — «ещё не опрашивал» или «ошибка», включите `/трассировка`, соберите
сундук в игре, подождите пару минут и пришлите `/трейслог` (ошибка опроса
теперь тоже пишется в лог). Важно: пока сундук не на перезарядке, его в
`stClanRewards` нет — таймер появится в `/таймеры` в течение ~5 минут ПОСЛЕ
сбора сундука, а не до.

### Осада аванпоста: предупреждение за час

Когда бот видит вашу осаду аванпоста (список `tOutpostSiegesMine`), он
автоматически поставит таймер, а **за час до его окончания** пришлёт отдельный
пуш: «🚩 Осада аванпоста скоро закончится — пора отправлять войска!» с остатком
и точным временем финиша. Если бот был выключен и опоздал — в сообщении будет
честный остаток, а не «час». Порог настраивается строкой в `.env`
(`SIEGE_PREWARN_SEC=3600` — секунды; выключить: `SIEGE_PREWARN_SEC=0`).

### Как добавить перевод нового таймера (по логу трассировки)

1. Пришлите боту **`/трассировка`** (или нажмите кнопку на экране `/апи`) —
   бот начнёт писать сырые ответы API в файл `data/trace.log` внутри папки бота.
2. Сделайте в игре то, чей таймер не отображается (откройте клановый сундук,
   заберите награду аванпоста), и подождите 2–3 минуты (1–2 опроса).
3. Пришлите **`/трейслог`** — бот пришлёт файл лога прямо в чат.
4. В логе найдите нужное место: сводка `data (ключи верхнего уровня)` покажет
   все списки и словари, раздел «Поля с датами/временем» — каждое поле-дату
   с JSON-путём (например `$.data.clanChest.readyAt`). Ниже — полный JSON ответа.
5. Впишите ключи в `translations.py` (или пришлите лог разработчику) и
   перезапустите бота (`start.bat`).

Лог растёт до ~2 МБ, потом старая копия переезжает в `trace.log.old` — диск не
переполнится. Трассировка выключается той же командой `/трассировка`.

## Обычная жизнь после настройки

- Играете как обычно (хоть на телефоне). Запустили улучшение — бот заметит
  его при следующем опросе (интервал 45 с) и сам поставит таймер, без
  вопросов; про финиш придёт пуш. Лишние сообщения — только «Готово ✅».
- В любой момент: `/апи` — статус автотрекинга (режим, жив ли ключ, когда
  был последний опрос, сколько таймеров поставлено).
- **Ключ продлевается сам**: при каждом старте, при любом 401 и превентивно
  раз в 6 часов бот делает auth — сервер снова принимает запросы. Если игра
  переподключилась и сбросила ваш ключ — бот заметит 401, реанимирует ключ
  и продолжит работу; вы этого даже не заметите (разве что пара опросов
  пропустится).
- **initData истекает редко** (у пользователя жила минимум 3 дня). Когда
  всё же истечёт: с юзерботом бот сам добудет новую и сохранит в .env;
  без него придёт сообщение «запустите login_bot.bat или положите свежий
  fomo.txt» — раз в несколько дней/недель, на ваш выбор.
- Если initData временно не принята, бот переходит в медленный опрос
  (раз в 5 минут) и сам сообщит, когда снова заработает.
- Боитесь «лишних» таймеров (кулдауны магазина и т.п.)? Пришлите `/вопросы` —
  бот начнёт показывать список с кнопками Да/Нет, и всё чужое отсеивается
  кнопкой «Нет» (и больше не предложится). Вернуть тишину — ещё раз
  `/вопросы`. Если лишнее уже добавилось — отмените кнопкой ❌ в `/таймеры`.

### Ограничения (честно)

- **ПК должен быть включён** — бот опрашивает API с вашего компьютера.
  Сон ПК = пауза. Если надоест — тот же бот переезжает на VPS за 10 минут
  (вариант Б), папка и база переносятся копипастой.
- Юзербот-сессия — это ваш аккаунт Telegram, открывающий мини-апп по
  расписанию. Это стандартная механика Telegram (та же, что у кликеров),
  но теоретически её может не одобрить сам Telegram — используйте на свой
  страх; риск минимален, попытки редкие (раз в несколько дней/недель).
- Если игра сменит API — автотрекинг покажет ошибку в `/апи`; пришлите
  свежий `fomo.txt` + `trace.log` (/трейслог), поправим разбор.

### Диагностика: если автоматика не справилась

В 95% случаев файл fomo.txt решает всё. Если бот написал «не нашёл
эндпоинт» или хотите разобрать трафик вручную — есть консольный инструмент:

```bash
# отчёт по содержимому HAR: эндпоинты, поля-таймеры, токен
.venv\Scripts\python.exe tools\har_inspect.py fomo.txt
# то же + авто-запись настроек в .env + контрольный запрос к API
.venv\Scripts\python.exe tools\har_apply.py fomo.txt
```

`har_inspect.py` создаёт **har_report.txt** — пришлите его, и я подстрою
разбор ответа под реальную структуру игры (если автомата что-то не устроило).

### Если что-то пошло не так

| Симптом | Причина / решение |
|---|---|
| DevTools пустой, запросов нет | Запись Network надо включить **до** перезагрузки мини-аппа; повторите шаг 4 |
| В HAR только telegram.org | Игра грузит данные с собственного домена — пришлите `har_report.txt`, найдём фильтром |
| Клановые сундуки / награды аванпостов не появились | Эти таймеры видны, только пока награда на перезарядке; бот забирает их из `/user/data/all` раз в 5 минут — подождите один цикл. Долго не появляются — включите `/трассировка`, соберите сундук в игре, пришлите `/трейслог` |
| Часть подписей таймеров по-английски | Ключ ещё не в `translations.py` — работает фолбэк. Трассировка + два пункта из раздела «Новые таймеры и переводы» |
| Бот пишет «initData не принята» | Пора обновить initData: запустите `login_bot.bat` (один вход — и забудьте) или положите свежий `fomo.txt` в папку бота |
| Бот пишет «initData не принята», хотя юзербот есть | Сессия могла слететь: запустите `login_bot.bat` ещё раз (вход займёт минуту) |
| Ответ сжат/нечитаем | В DevTools включите «Save all as HAR **with content**» (но и без него сработает) |
| Watcher не видит файл | Файл должен лежать именно в корне папки бота (имя `fomo*`) или в `token_updates/` (не в `done/`), расширение .har/.txt/.curl/.log/.json |
| `ZoneInfoNotFoundError: 'No time zone found with key ...'` при первом /start | На Windows у Python нет базы часовых поясов. Лечится: `.venv\Scripts\pip install tzdata`. В актуальной версии ставится автоматически при первом запуске `start.bat` (и входит в `requirements.txt`) |
| Батник пишет `'ход' is not recognized...` / `'�' is not recognized...` | Старые .bat с кириллицей ломались парсером cmd (кодировки). В актуальной версии все .bat — чистый ASCII и не зависят от кодовой страницы. Перекачайте zip и замените .bat, либо запустите скрипт напрямую: `.venv\Scripts\python.exe login_userbot.py` |
| `403 RECAPTCHA_CHECK…` при входе в `login_bot.bat` | Анти-спас Telegram на публичных api-ключах. Впишите свои `USERBOT_API_ID` / `USERBOT_API_HASH` из my.telegram.org (скрипт входа сам предложит и сохранит) и запустите вход заново |

### Про безопасность и правила игры

Бот читает только **свои** данные через запросы `/user/data/timers` и
похожие (read-only) — это то же самое, что вы видите глазами в приложении.
Никаких действий за вас он не совершает и автоматизацией геймплея не
является. initData и юзербот-сессия хранятся локально в вашей папке
(initData — в `.env`, сессия — в `userbot.session`) и служат только для
чтения таймеров; ни игра, ни бот не могут писать что-то в ваш Telegram.
Тем не менее это неофициальный инструмент: теоретически политика игры может
этого не одобрять — используйте на свой страх, риск минимальный, но не
нулевой.

## FAQ

**Пуши приходят с задержкой?**
Telegram доставляет мгновенно; задержки бывают, если в самом Telegram отключён
фоновый режим/автозапуск. Проверьте: Настройки ТГ → Уведомления и звук;
в Android — не «усыплён» ли Telegram (Настройки → Батарея → Без ограничений).

**Бот молчит после `/start`?**
Проверьте токен в `.env` и `journalctl -u fomo-timer -f`. Если у вас уже был
запущен другой экземпляр бота с этим токеном — остановите его (два polling-
процесса с одним токеном конфликтуют).

**Бот перезапустился — таймеры сгорят?**
Нет. Всё лежит в `data/fomo_timers.db`; после старта бот догонит пропущенные
уведомления с пометкой «опоздание N мин».

**Можно вернуть предупреждение «за минуту до конца»?**
Да: в `.env` поставьте `WARN_ENABLED=true` и перезапустите.

**Часовой пояс?**
По умолчанию `Europe/Moscow`; меняется командой `/пояс`. Влияет только на
отображение времени финиша, на точность — нет.

**Что за таймеры с метками «🎁», «📦», «✨»?**
🎁 — клановый сундук на перезарядке («· N ч» = сколько часов перезарядка; сундуков
столько, каков уровень клана), 📦 — награда аванпоста, ✨ — прочие кулдауны.
Первые два бот берёт из `/user/data/all` раз в 5 минут; перевести подпись —
раздел «Новые таймеры и переводы».

**Кнопка меню ☰ открыла не таймеры, а старый адрес / ошибку?**
Адрес туннеля обновляется при старте бота — убедитесь, что бот запущен
(в консоли есть строка «Мини-апп: кнопка меню указывает на …»), затем
перезайдите в чат с ботом или пришлите `/app`. Если туннель не поднялся —
смотрите `data/tunnel.log` и строку 🎯 в `/апи`.

**Заглушил группу — куда делись пуши?**
Никуда не делись: тихий режим выключает пуши для выбранной группы, пока
вы не включите звук обратно (колокольчик 🔕 в мини-аппе). Таймеры при этом
продолжают ставиться и видны на панели. Накопленные за время тишины «Готово»
не догоняются — они уже отображались в панели.

**Хочу мини-апп без cloudflared / со своим адресом**
Впишите в `.env`: `WEBAPP_PUBLIC_URL=https://ваш-адрес` (должен быть HTTPS с
действительным сертификатом) — например, адрес туннеля вашего VPS. Тогда
cloudflared не скачивается. Либо отключите совсем: `WEBAPP_ENABLED=false`.

## История версий

### 0.0.4-alpha (текущая)

- **🎯 Мини-приложение в боте** — новый визуальный слой поверх уведомлений:
  кнопка меню ☰ (или `/app`) открывает панель со ВСЕМИ таймерами сразу:
  живые отсчёты, прогресс-бары, группы, время финиша в вашем поясе.
- **Кнопки управления** в мини-аппе: тихий режим по группам (🔔/🔕) и глобальный
  (заглушённая группа не шлёт пушей и не накапливает их), отмена таймера (✕),
  «🔄 Обновить» (внеочередной опрос API игры), «🎮 Игра».
- Новые модули: `webapp_server.py` (HTTP-сервер на 127.0.0.1 + официальная
  проверка подписи initData Telegram + JSON API), `webapp_prefs.py` (тихий
  режим, переживает рестарт), `tunnel.py` (публичный HTTPS-адрес через
  бесплатный cloudflared — без регистрации; качается сам при первом запуске),
  `webapp/index.html` (страница панели; тема подстраивается под Telegram).
- Планировщик уважает тихий режим: заглушённые группы не шумят, но таймеры
