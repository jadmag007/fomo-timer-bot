# ⏱ Fomo Timer Bot — напоминания для Fomo Fighters

Личный Telegram-бот, который помнит за вас все игровые таймеры: стройки,
тренировки, лечение, осады аванпостов, перезарядки клановых сундуков и
наград аванпостов. Запустили улучшение в игре — тапните в боте длительность,
и в момент финиша придёт «Готово ✅». А если настроить автотрекинг, бот
сам увидит таймеры из API игры и напомнит без единого нажатия.

Текущая версия: **0.1.1.0** (видна в `/start`, `/апи` и на странице таймеров).

---

## Возможности

| | |
|---|---|
| ⏱ Ручные таймеры | Чипы 5м…24ч в меню, `/т 22:24 лесопилка`, форматы как в игре |
| 🤖 Автотрекинг | Бот сам опрашивает API игры и ставит таймеры: стройки, войска, лечение, ✨-кулдауны |
| 🎁 Клановые сундуки | «🎁 Клановый сундук · N ч» (перезарядка = уровню клана) + мгновенный «пора забрать» |
| 📦 Награды аванпостов | Таймер на перезарядку + «🚩 пора отправлять войска» за час до конца осады |
| 🌐 Страница в браузере | Все таймеры на одном экране (`http://127.0.0.1:8080` на устройстве с ботом): живые отсчёты, тихий режим, отмена, обновление опроса |
| ⏸ Пауза | Ушли от компьютера — пуши не приходят, по возвращении одна сводка пропущенного |
| 🔄 Живучесть | Пуши не теряются при обрыве сети: недоставленное досылается, ключ игры продлевается сам |

## Быстрый старт (Windows, 5 минут)

1. Распакуйте `fomo-timer-bot.zip` в любую папку (например, `F:\FOMO\fomo-timer-bot`).
2. Дважды щёлкните `install.bat` — он сам найдёт/установит Python, создаст
   окружение, поставит зависимости и спросит **токен от @BotFather**
   (в Telegram: `/newbot` у BotFather → скопировать токен → вставить в окно).
3. Бот запустится сам. Дальше — `start.bat` (он же перезапускает бота при падении).

### macOS / Linux / VPS

```bash
bash install.sh    # тот же шаг: окружение + токен
bash start.sh      # (после git clone с Windows запускайте через bash — см. TERMUX.md)
```

### Android (Termux) 📱

Тот же бот целиком на телефоне: `install.sh` и `start.sh` сами понимают
Termux (wake-lock, готовое колесо pydantic-core из зеркала TUR PyPI —
без компиляции, запуск без venv), страница таймеров открывается
в браузере того же телефона (`http://127.0.0.1:8080`). Пошаговая инструкция — **TERMUX.md**.

Для работы 24/7 удобнее VPS (`install.sh` + `start.sh` в фоне или через
`systemd/fomo-timer.service`) либо Docker (`docker-compose.yml`). Помните:
пуши приходят только когда ПК с ботом включён и не спит.

## Как пользоваться

- **Формат как в игре:** `22:24` = 22 мин 24 с, `1:28:10` = 1 ч 28 м 10 с,
  а ещё `45м`, `1ч 30м`, `2ч`.
- Кнопка-чип в меню → таймер готов; или текстом: `/т 22:24 лесопилка`.
- `/таймеры` — список активных, там же кнопки отмены.
- `/tz` — часовой пояс (по умолчанию Europe/Moscow).

## Автотрекинг: бот ставит таймеры сам

Два способа включить (любой, один раз):

1. **fomo.txt — самый простой.** Откройте мини-апп игры через
   web.telegram.org, нажмите F12 → Network → перезапустите игру → правый
   клик на запросе `/telegram/auth` → «Copy all as HAR» → сохраните в файл
   `fomo.txt` и положите в папку бота (или перетащите на
   `update_token.bat`). Бот сам разберёт файл, включится и напишет в личку.
2. **login_bot.bat — дальше всё совсем без файлов.** Одноразовый вход
   юзербота (телефон → код из Telegram → пароль 2FA): бот сам будет
   добывать свежие ключи, когда игра их инвалидирует.

Проверить статус: `/апи` — HTTP-код последнего опроса, сколько нашёл и
добавил, жив ли ключ, работает ли опрос сундуков и адрес страницы таймеров.
По умолчанию находки ставятся молча; кнопка 🔔 в `/апи` (или `/вопросы`)
включает подтверждение «Да/Нет» перед добавлением.

### Клановые сундуки и награды аванпостов

- Раз в 5 минут бот опрашивает `/user/data/all` и ставит таймеры на
  перезарядку: «🎁 Клановый сундук · N ч» (у клана уровня N — сундуки
  `clan_1..N`, перезарядка каждого — N часов) и «📦 Награда аванпоста».
- Важный нюанс: награда видна API только **пока она на перезарядке**.
  Собрали сундук в игре → в течение ~5 минут таймер появится в `/таймеры`,
  и когда он сгорит — придёт мгновенный пуш «пора забрать». Если сундук
  давно собран и уже стоит готовый — таймер на него не поставить, нечего
  напоминать.
- Статус опроса сундуков виден в `/апи` (строка «🎁 Сундуки/аванпосты»)
  и пишется в трассировку `/трассировка` → `/трейслог`.

### Осада аванпоста: предупреждение за час

Когда ваши войска осаждают аванпост, за час до конца осады придёт
отдельный пуш «🚩 пора отправлять войска». Порог настраивается:
`SIEGE_PREWARN_SEC=3600` в `.env` (0 — выключить).

## 🌐 Страница таймеров в браузере

Команда `/app` подскажет адрес; сама страница открывается в ОБЫЧНОМ браузере
на том устройстве, где запущен бот: `http://127.0.0.1:8080` (порт другой,
если 8080 занят). На экране — все таймеры сразу: живые отсчёты, прогресс-бары,
колокольчики тихого режима по группам, отмена таймеров, кнопка «🔄 Обновить»
для внеочередного опроса игры. Уведомления в чат работают как раньше и от
страницы не зависят.

Сервер слушает только `127.0.0.1` — наружу ничем не торчит: страница видна
лишь на устройстве с ботом. Мини-апп в Telegram (кнопка меню, туннель
cloudflared) убран до лучших времён — вернёмся позже, код сохранён в истории
git.

## ⏸ Пауза: ушёл от компьютера

Кнопка «⏸ Пауза» в главном меню (или `/пауза`):

- игровые пуши («Готово ✅», предупреждения, предложения Да/Нет) не
  отправляются вовсе;
- таймеры при этом продолжают ставиться, автотрекинг и страница таймеров работают;
- всё, что завершилось в паузу, попадает в список пропущенного — после
  «▶️ Продолжить» придёт ОДНА сводка, без спама;
- пауза переживает рестарт бота (хранится в `data/pause.json`);
- редкие системные предупреждения (ключ игры мёртв)
  доходят и на паузе — их лучше не пропускать.

### 🔕 Тихий режим

Кнопка-колокольчик на странице таймеров глушит отдельные группы (например,
клановые сундуки, если их много) или все сразу. Замьюченные таймеры
завершаются тихо, без догоняющих пушей; всё видно на самой странице.

## Настройки (.env)

Основные ключи (полный список с комментариями — в `.env.example`):

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather |
| `DEFAULT_TZ` | Europe/Moscow | Часовой пояс по умолчанию |
| `WARN_ENABLED` | false | Предупреждение «через минуту» до финиша |
| `API_POLL_INTERVAL` | 45 | Секунд между опросами игры (не меньше 30) |
| `FOMO_ALL_INTERVAL` | 300 | Секунд между опросами сундуков/аванпостов |
| `SIEGE_PREWARN_SEC` | 3600 | За сколько предупреждать про конец осады (0 — выкл) |
| `API_OWNER_TG_ID` | пусто | Ваш tg_id (@userinfobot) — кому ставить авто-таймеры |
| `WEBAPP_ENABLED` | true | Страница таймеров в браузере |
| `WEBAPP_PORT` | 8080 | Локальный порт (занят — возьмёт следующий) |

Руками в `.env` заполнять почти ничего не нужно: fomo.txt и login_bot.bat
всё впишут сами.

## Обновление на новую версию

1. Скачайте свежий `fomo-timer-bot.zip` в папку проекта (рядом с
   `github_push.bat`).
2. Запустите `github_push.bat` — он сам распакует архив поверх папки
   (`.env`, `data/`, сессии и сам батник не трогаются), а затем опубликует
   обновление в ваш репозиторий; и архив, и батник внесены в `.gitignore`,
   наружу личное не уедет. Личная инструкция по GitHub — в `GITHUB.md`.
3. Перезапустите `start.bat`.

Обновления можно тянуть и с GitHub: `start.bat` при каждом запуске тихо
проверяет репозиторий и, если там версия новее, ставит её сама. На другом
ПК достаточно `git clone` + `install.bat` (личные файлы переносятся руками).

## Структура проекта

```
fomo-timer-bot/
├─ bot.py             # точка входа: polling + фоновые задачи + страница таймеров
├─ handlers.py        # все команды и кнопки бота
├─ timers.py          # планировщик пушей (T-0 / за час / сводка паузы)
├─ api_poller.py      # автотрекинг: опрос API, парсеры, дедуп
├─ fomo_client.py     # нативный клиент игры: сам подписывает и сам чинит ключ
├─ pause_state.py     # пауза (persist data/pause.json + список пропущенного)
├─ db.py              # SQLite (data/fomo_timers.db)
├─ util.py            # парсер «22:24» / «1ч 30м», время, пояса
├─ translations.py    # русские метки групп и ключей игры
├─ watcher.py         # авто-подхват fomo.txt / HAR из token_updates/ и корня
├─ webapp_server.py   # локальный HTTP-сервер страницы таймеров (+/api/state…)
├─ webapp/index.html  # экран страницы таймеров
├─ webapp_prefs.py    # тихий режим (data/webapp_settings.json)
├─ userbot.py / login_userbot.py  # добыча свежей initData (login_bot.bat)
├─ apitrace.py        # трассировка API (data/trace.log, ротация)
├─ tools/har_*.py     # разбор HAR-файлов (можно и без них — fomo.txt проще)
├─ install.bat / start.bat / update_token.bat / github_push.bat / login_bot.bat
├─ install.sh / start.sh / login_bot.sh           # то же для macOS/Linux/Android
├─ TERMUX.md                                       # гайд: бот на андроиде (Termux)
├─ systemd/, Dockerfile, docker-compose.yml       # для VPS
└─ README.md / GITHUB.md / .env.example / .gitignore
```

Личные данные живут только у вас и в git/zip не попадают: `.env`,
`data/` (база, trace.log, пауза), `userbot.session`, `fomo.txt`,
`token_updates/`, логи.

## Если что-то пошло не так

| Симптом | Что это и что делать |
|---|---|
| `ZoneInfoNotFoundError: 'UTC'` при старте | Не установлена база поясов: `pip install tzdata` (start.bat сам долечивает) |
| Страница таймеров «нет связи с ботом» | ПК спит/бот выключен — страница берёт данные прямо с того же устройства, `/апи` покажет статус бота |
| Много ошибок `WinError 1236` / `TelegramNetworkError` | Обрывается связь с Telegram (Wi-Fi/провайдер). Это не поломка: бот сам ретраит с паузами и доставит всё, как сеть вернётся |
| `HTTP 401 invalid_hash` в логах | Ключ игры устарел — бот сам реанимирует его через /telegram/auth; если не вышло: свежий fomo.txt или `login_bot.bat` |
| Пуш не пришёл вовремя, бот был офлайн | Придёт догоном с пометкой опоздания (держится до 10 минут) |
| Порт 8080 занят | Бот сам возьмёт следующий свободный |
| «Сундук собрал, а таймера нет» | Таймер ставится только ПОКА награда на перезарядке; проверьте `/апи` (строка 🎁) через ~5 мин после сбора |
| Бот пишет «не доставлено … повторю позже» | Сеть лежала — недоставленные пуши досылаются автоматически |

## История версий

- **0.1.1.0** — МИНИ-АПП В TELEGRAM УБРАН ДО ЛУЧШИХ ВРЕМЁН (вернёмся — код
  останется в истории git): удалены туннель cloudflared (`tunnel.py`), кнопки
  WebApp/меню, валидация initData и настройки `WEBAPP_PUBLIC_URL` /
  `WEBAPP_TUNNEL_PROTOCOL` / `WEBAPP_LOCAL_DEBUG`. Основным способом работы
  стала ЛОКАЛЬНАЯ СТРАНИЦА ТАЙМЕРОВ в обычном браузере на устройстве с ботом:
  `http://127.0.0.1:8080` (порт подскажет `/app` и `/апи`). Страница стала
  проще и надёжнее: без Telegram-обвязки, замка и туннельных проверок; тихий
  режим, отмена и «Обновить» работают как раньше. Пуши и автотрекинг не тронуты.
  Дополнительно в 0.1.1.0: вход юзербота (login_bot.bat) теперь сам
  включает автотрекинг — сохраняет свежий ключ в .env (FOMO_INIT_DATA)
  и ставит API_ENABLED=true. Работающий бот замечает это без
  перезапуска (проверяет .env раз в 15 секунд), а если сессия есть,
  но ключа нет — добывает его сам. fomo.txt после входа юзербота не
  нужен вовсе. start.sh (Termux/Linux) при ошибке конфигурации (код 2)
  останавливается с подсказкой вместо вечного цикла перезапусков —
  как start.bat на Windows.
- **0.1.0.8** — install.sh сам обновляется из git: перед установкой уводит
  локальные правки служебных файлов в stash (возврат: `git stash pop`),
  тянет свежий код и перезапускает себя новой версией. Лечит случай «git pull
  падает с error: Your local changes ... would be overwritten by merge» —
  из-за него телефон неделями запускал старый установщик, и фиксы до него
  не доезжали. Плюс мягкое сообщение вместо ошибки при запрете обновлять
  сам pip в Termux.
- **0.1.0.7** — найден главный виновник повторных сбоев установки на Termux:
  install.sh ставил готовое колесо pydantic-core 2.41.5, но следующий шаг
  (`pip install -r requirements.txt`) затирал его свежим pydantic 2.13.x,
  которому нужно ядро 2.46.x — готовой сборки под андроид нет, и pip падал
  в сборку Rust. Теперь ПАРА pydantic 2.12.5 + pydantic-core 2.41.5 ставится
  заодно и ДО aiogram; плюс pure-python флаги yarl/multidict/frozenlist/
  propcache, пропуск шага если pydantic уже стоит, баннер версии установщика
  (видно на скриншоте, какой установщик запущен) и внятная подсказка
  (git pull / VPN) со стопом, если ядро всё же не встало.
- **0.1.0.6** — установка на Termux без компиляции: pydantic-core ставится
  готовым колесом android_24_arm64_v8a из зеркала TUR PyPI (официальное
  PyPI-зеркало Termux User Repository); запасной путь — Rust из репозитория
  Termux + maturin. В TERMUX.md — пошаговый перенос .env и data через свой
  git-репозиторий.
- **0.1.0.5** — фикс установки зависимостей на Termux: в репозитории Termux
  нет готовых aiohttp/pydantic, а pydantic-core (Rust-расширение aiogram)
  не собирается — rustup не поддерживает android-таргет. install.sh теперь
  ставит rust+binutils из репозитория Termux (тот умеет
  aarch64-linux-android), aiohttp переводится в pure-python
  (AIOHTTP_NO_EXTENSIONS), честные цифры: ~1.5 ГБ и 10-25 минут на разовую
  установку. Troubleshooting: pydantic-core/Rust-not-found.
- **0.1.0.4** — фикс запуска на андроиде после git clone: git при пуше с
  Windows не сохраняет бит «исполняемый», поэтому `./install.sh` падал с
  «Permission denied». Команды в гайдах переведены на `bash install.sh` /
  `bash start.sh` (работает всегда), install.sh сам возвращает права всем
  .sh при каждом запуске и стартует start.sh через bash. В TERMUX.md вшит
  адрес репозитория (больше не плейсхолдер) + разбор проблемы в
  troubleshooting.
- **0.1.0.3** — Termux/Android: бот целиком живёт на телефоне. install.sh
  и start.sh сами распознают Termux (wake-lock против «засыпания», готовый
  python-aiohttp из репозитория Termux вместо десяти минут компиляции,
  запуск без venv); tunnel.py качает arm64-сборку cloudflared (раньше на
  андроиде был Exec format error); гайд TERMUX.md — установка, перенос с
  ПК, автозапуск через Termux:Boot, правило «один бот = один экземпляр»
  (иначе 409 Conflict). На мобильном интернете туннель часто работает —
  у оператора порт 7844 обычно не заблокирован.
- **0.1.0.2** — локальный режим мини-аппа: на компьютере с ботом страница
  открывается в обычном браузере (`http://127.0.0.1:8080`) без
  Telegram-подписи — спасение, когда провайдер режет туннель (error 1033).
  Доступ только с того же ПК; трафик из интернета через туннель отсекается
  по служебным заголовкам Cloudflare и несовпадению Host. В сообщении о
  блокировке туннеля бот теперь сам подсказывает локальный адрес; в
  браузере работают все кнопки, включая «🎮 Игра».
- **0.1.0.1** — github_push.bat стал «одной кнопкой»: сам распаковывает
