# GitHub: публикация и автообновления (личная инструкция)

> ⚠️ **Этот файл личный**: он добавлен в `.gitignore`, поэтому на GitHub
> НЕ публикуется и остаётся только в вашей папке (и в zip от разработчика).
> Публиковать его нельзя: ссылки/ники из него — часть вашего workflow.

Код бота хранится на github.com — это и резервная копия, и удобный способ
переносить бота между компьютерами (в том числе на VPS, Вариант Б: вместо
перекачки zip — одна команда `git clone`). Схема работы максимально простая:

- **выложить код на GitHub** — один двойной клик по `github_push.bat`;
- **забрать обновления** — `start.bat` при каждом запуске сам проверяет GitHub
  и сам устанавливает новую версию.

### Разовая настройка (5 минут)

1. **Установите Git** (если ещё нет) — любым способом:
   - PowerShell: `winget install --id Git.Git -e`
   - или скачайте установщик с [git-scm.com/download/win](https://git-scm.com/download/win)
     — дальше «Next-Next-Finish», настройки по умолчанию подходят.
   После установки откройте окна/проводник заново, чтобы PATH обновился.
2. **Создайте репозиторий** на сайте: вы зарегистрированы на github.com →
   нажмите **«+»** (правый верхний угол) → **New repository** →
   имя `fomo-timer-bot` → выберите **Private** (рекомендую: у вас будет
   своя копия личного инструмента) → ⚠️ **НЕ добавляйте** ни README, ни
   .gitignore, ни license — репозиторий должен быть пустым → **Create**.
3. **Скопируйте адрес репозитория**: на странице нового репозитория зелёная
   кнопка **«<> Code»** → вкладка HTTPS → ссылка вида
   `https://github.com/ВАШ_НИК/fomo-timer-bot.git`.

### Публикация — один файл

Запустите **`github_push.bat`** в папке бота. Он сам:

1. проверит, что Git установлен (подскажет команду установки, если нет);
2. при первом запуске попросит вставить адрес репозитория (сохранит его в
   локальный `github_repo.txt` — в git он не попадёт) и ваш ник на GitHub
   (нужен для подписи коммитов, спрашивается один раз);
3. соберёт все изменения в коммит и отправит на GitHub.

При первом пуше Git откроет **окно браузера** «Authorize Git Credential
Manager» → нажмите **Authorize** — и всё, доступ сохранён навсегда (это
официальный вход через сайт, пароль вводить нигде не нужно).

Последующие публикации — тот же один клик по `github_push.bat`: уедут
только изменения.

### Что точно НЕ уедет на GitHub

В проекте лежит `.gitignore` — список личных файлов, которые git публиковать
запрещено. Под защитой:

| Файл/папка | Почему личное |
|---|---|
| `.env` | Токен бота, initData игры, ключи юзербота |
| `userbot.session` | Ваш вход в Telegram |
| `fomo.txt`, `*.har`, `token_updates/` | Снимки трафика: внутри initData аккаунта |
| `data/` | База таймеров, логи трассировки |
| `.venv/`, `__pycache__/`, `*.log` | Локальный мусор, качается заново за минуту |

### Обновление версии (вышел новый zip) — одна кнопка

1. Скачайте новый `fomo-timer-bot.zip` и просто положите его в папку бота
   (рядом с `github_push.bat`). Распаковывать руками не нужно.
2. Запустите `github_push.bat` — он сам:
   - распакует архив поверх папки, НЕ трогая `.env`, `data/`, сессии и
     сам батник (если в архиве обновился и он — появится
     `github_push.bat.new`, и при следующем запуске подменится сам);
   - закоммитит изменения (в сообщении — версия из `config.py`);
   - запушит на GitHub.
3. Перезапустите бота (`start.bat`), чтобы новая версия заработала.

> Архива рядом нет? Батник просто опубликует текущее состояние папки.
> И zip, и `github_push.bat` внесены в `.gitignore` — на GitHub не уедут.

### Автообновление при запуске бота

`start.bat` при каждом запуске тихо проверяет GitHub (2–3 секунды; если
интернета нет — просто запускается дальше). Если на GitHub версия новее —
бот пишет «update found, installing…», обновляется и стартует уже с новой
версией (её видно в `/start`). Личные файлы при этом не трогаются никогда.

> Нюанс: GitHub считается главной версией. Если вы сами правили код
> локально и не опубликовали это через `github_push.bat`, автообновление
> перезапишет правки версией с GitHub. Публикуйте свои изменения — и
> конфликтов не будет.

### Перенос на новый ПК (или VPS) через git

```bash
git clone https://github.com/ВАШ_НИК/fomo-timer-bot.git
cd fomo-timer-bot
install.bat      # Windows (на VPS: install.sh + start.sh)
start.bat
```

Личных файлов на GitHub нет, поэтому `.env` (токен) и `userbot.session`
нужно либо перенести со старого ПК вручную, либо создать заново
(`install.bat` спросит токен; `login_bot.bat` — повторный вход юзербота).

### Если что-то пошло не так (git)

| Симптом | Решение |
|---|---|
| `'git' is not recognized` | Git не установлен или окно открыто до установки. Установите (команда выше) и откройте окно заново |
| Окно авторизации не появилось / закрылось случайно | Просто запустите `github_push.bat` ещё раз |
| `Authentication failed` при пуше | На сайте: Settings → Developer settings → Personal access tokens (classic) → Generate new token (отметьте `repo`) → при запросе логина в консоли введите ник, вместо пароля — этот токен |
| `remote: Repository not found` | Адрес неверный или репозиторий Private, а вы не вошли. Проверьте ссылку; исправить: `git remote set-url origin https://github.com/НИК/fomo-timer-bot.git` |
| `push rejected` (на GitHub что-то уже есть) | Скрипт сам предложит перезаписать удалённую версию вашей (клавиша Y). Это нормально при первой публикации |
| Случайно опубликовали лишнее | Удалите файл локально, закоммитьте заново; если секрет (токен) — сразу смените его (BotFather → /revoke) — история git его помнит |
